# Nhlanhla Fakude Portfolio

[![Validate and deploy site](https://github.com/Fakude/Profile/actions/workflows/pages.yml/badge.svg)](https://github.com/Fakude/Profile/actions/workflows/pages.yml)

Personal portfolio site showcasing projects, skills and contact information for Nhlanhla Fakude.

## Run locally

Open `index.html` in a modern browser. No framework, build step or environment variables are required.

## Deployment

The GitHub Actions workflow validates browser JavaScript on every push and pull request. Pushes to `main` automatically deploy the site with GitHub Pages.

## Project structure

- `index.html` — semantic portfolio content
- `port.css` — responsive styling
- `port.js` — client-side interaction
- `image.png`, `portimg.jpg` and `pexels-photo-8134609.jpeg` — visual assets
- `.github/workflows/pages.yml` — CI and continuous deployment

## Portfolio evidence

Demonstrates personal-brand presentation, responsive web development, automated quality checks and GitHub Pages deployment.
